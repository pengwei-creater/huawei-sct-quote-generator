# 报价规则手册

> 本文件是工具的行为规范：解析、归类、定价、书写格式。技能形态下同一套规则放在 `SKILL.md`。

## 1. 工作流

```bash
pip install openpyxl

# 1) 解析 SCT → JSON
python -m quote_generator parse "<SCT文件或目录>" -o sct.json

# 2) 按规则整理报价行，写入 quote_config.json（结构见 examples/）
# 3) 生成报价单
python -m quote_generator build quote_config.json -o "报价单.xlsx"

# 4) 校验：脚本打印的合计 必须等于 SCT 的 projectTotalPrice
```

- 不要手写 xlsx 样式，一律走 `build()`，保证格式一致。
- `rows[].config` 用 `\n` 分行，一行一个配置项。
- 多个产品 = 多个 row；合计由脚本自动写 `=SUM(G2:G{last})`。

## 2. SCT 导出文件结构

工作表：`封面`、`免责声明`、`项目配置报价`（只有最后一张含数据）。

`项目配置报价` 的列：

| 列 | 含义 |
|---|---|
| A | 标记列：`partType.1`=硬件、`partType.0`=服务/软件、`partnumber.*`=物料码、`*TotalPrice`=合计行 |
| C | 序号（非空即父产品） |
| D | 描述（物料名） |
| E | 总数 |
| F | 成交单价 |
| G | 成交总价 |

三种合计行：`productTotalPrice`（设备）、`serviceTotalPrice`（服务）、`projectTotalPrice`（项目）。

## 3. 产品分类

IT 产品（BOM 可直接拼配置）：`OceanStor Dorado`、`OceanStor Pacific`、`OceanStor 5xxx`、
`FusionCube`、`Atlas`、`OceanProtect`。

数通产品（需查官网技术规格）：`CE*` 交换机、`AR*` 路由器、`AirEngine*` AP、`USG*` 安全网关。
规格页形如 `https://e.huawei.com/cn/products/{品类}/{子品类}/{产品系列}`。

光模块、跳纤、电源、滑轨等配件不作为分类依据。

## 4. 配置详情写法

```
机箱：完整型号(关键规格)
CPU：数量*规格(核心数 频率)
缓存：容量
电源：数量*功率 类型
内存：数量*容量 类型 速率
接口：板载口、扩展卡口（用、分隔）
硬盘：SSD在前HDD在后，用、分隔，数量*型号
网卡：数量*规格
RAID卡：型号
软件：许可名称-数量
服务：含...
```

硬性要求：

- 每项占一行，行首不留空格。
- CPU、缓存、网口从机箱描述里剥离，单独成行。
- 硬盘合并一行：容量升序、SSD 在前 HDD 在后、`、` 分隔。
- 数量写在型号前：`8*1Gb ETH`，不写 `1Gb ETH*8`。
- 网口速率依**光模块**判定（SFP+=10G、SFP28=25G），不依网卡。
- 电源用「功率+类型」，不写物料编码。
- 禁止内部代号、物料编码、`XX已合并` 之类的处理痕迹。

## 5. 定价规则

- 设备单价取父产品 F 列，总价取 G 列。
- **随设备服务默认打包**：工程应用支持、安装、规划设计与实施、灾备场景化实施、SSD 寿命保障，
  按 `Σ服务金额 / 设备数量` 并入设备单价，不单独列行。
- 只有**没有设备归属的纯服务**（如业务迁移、独立运维）才单列。
- 打包或拆分**不得改变合计**，合计必须等于 SCT `projectTotalPrice`。
- 实施服务单列仅在用户明确要求时使用，价格取 SCT 该父产品成交价。
- 支持统一倍率（如 ×1.2）与「指定价格」分发场景。

## 6. 多产品项目

- 每个独立产品一行；DCS 虚拟化套件与 FusionCube 写在同一行，DCS 许可并入软件行。
- 服务类产品单独成行。
- 超融合按节点拆分数量：`每节点数量 = 总数量 / 节点数`，首行注明「本次共N节点，以下为单节点配置」。

## 7. 格式规范

| 项 | 值 |
|---|---|
| 字体 | 等线 12pt（表头加粗白字） |
| 表头填充 | `FF76453B` |
| 金额格式 | `0.00_);[Red](0.00)`，其余列「常规」 |
| 列宽 | A=6.125 B=29–36 C=83.375 D=6.125 E=6 F=14 G=12–16 H=19 |
| 行高 | 按内容自动：约 15.75pt/行 + 6pt，最低 30pt |
| 合计行 | 合并 A:F，G 列 `=SUM(...)` |
| 声明区 | 等线 9pt 加粗 |

## 8. 输出

- 位置：与 SCT 文件同目录（或用户指定目录）。
- 命名：`{产品名}报价单{YYYYMMDD}.xlsx`；多代理商时 `{项目名}报价单_{代理商名}.xlsx`。
